# Echoes of the Jungle: Temple of Eternity

Windows 64-bit standalone build for Unity 6000.3.24f1.

## Run

Open `EchoesJungle-Windows64/UnityProject.exe` on Windows. Keep the complete `EchoesJungle-Windows64` folder together; the executable requires the neighboring `UnityProject_Data`, `UnityPlayer.dll`, `D3D12`, `MonoBleedingEdge`, and crash-handler files.

This repository contains the playable build package. The Unity source project and imported asset packs remain in the local workspace.
